# Lesson 3 — 배포 + A/S

## 멤버

- 강신안 + 최완규(외부인원)
- 개회(09:00–09:30)는 대표님

## 개요

Vercel + Supabase 8시간 실습. 1·2회차에서 만든 팀 프로젝트를 실제로 배포하고, 데이터 저장소를 연결해 동작하는 팀 사이트로 완성한다.

**오전은 전원 같은 화면으로 따라하기, 오후는 각자 팀 프로젝트에 적용하며 밀착 코칭**하는 2블록 구성이다. 2회차까지 설계·개발 코칭이 끝난 상태이므로 3회차의 본론은 새 도구 두 개(Vercel·Supabase)를 익히는 것이고, 도구 학습은 전원 같은 화면이 유리하다.

## 하루 구성

### 오전 — 공통 따라하기 (전원 같은 화면)

| 시간 | 구분 | 내용 |
|------|------|------|
| 09:00–09:30 | 개회 | 대표님 인사 — 오늘 목표 · 향후 진행 · 강사 소개 |
| 09:30–10:00 | MCP 연결 | 통로 열기 — `claude mcp add` → `/mcp` 인증 → `npx vercel login` |
| 10:00–11:00 | 따라하기 ① | Vercel 배포 (첫 3분 "배포란") |
| 11:00–12:00 | 따라하기 ② | Supabase 데이터 → **화면 표시까지** (오전 체크포인트) |

### 오후 — 각자 프로젝트 코칭 (강사 2인 순회)

| 시간 | 구분 | 내용 |
|------|------|------|
| 13:00–13:30 | 범위 합의 | 오늘 배포할 범위 좁히기 · 데이터 항목 적기 |
| 13:30–15:00 | 코칭 ① | 내 프로젝트 배포 — **체크포인트: 팀 사이트 주소** |
| 15:00–16:30 | 코칭 ② | 내 데이터 연결 — **체크포인트: 데이터 화면 표시** |
| 16:30–17:15 | 코칭 ③ | 핵심 기능 1개 + 확인 습관 |
| 17:15–18:00 | 발표 | 팀별 시연 · Q&A · 사후 A/S 안내 |

시간표 한 장 요약(트랙·체크포인트·오류 모음 포함): [강의 일정표](강의일정표.html).
