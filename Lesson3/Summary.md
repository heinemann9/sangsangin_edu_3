# Lesson 3 — 배포 + A/S

## 멤버

- 강신안 + 최완규(외부인원)

## 개요

Vercel + Supabase 8시간 실습 (팀별 프로젝트 기반). 1·2회차에서 정리한 팀 프로젝트를 실제로 배포하고, 데이터 저장소를 연결해 동작하는 팀 사이트로 완성한다. 이론은 최소화하고 팀별 실습 중심으로 진행한다.

교시별 상세 진행안(강사용 단계·코칭 포인트·산출물): [상세 진행안](data/Curriculum.md).

비개발자용 **Vercel 배포 따라하기**(로그인·GitHub 연결·배포·환경변수·재배포를 스크린샷으로 단계별 안내): [Vercel 배포 따라하기](data/Vercel-배포-따라하기.md).

## 교시별 구성

| 교시 | 주제 | 활동 | 산출물 |
|------|------|------|--------|
| 1 | 프로젝트 정리 & 목표 합의 | 팀 프로젝트 점검, 오늘 배포할 범위 정하기, 필요한 데이터 항목 적어보기 | 배포 범위·데이터 항목 정의 |
| 2 | 일단 배포부터 성공 | 팀 프로젝트를 GitHub에 올리기 → Vercel 연결 → 팀 사이트 주소 받기 | 배포된 팀 사이트 주소 |
| 3 | 배포 안정화 & 연결 준비 | 배포 오류 잡기, 환경변수 세팅, 자동 재배포 확인, Supabase 연결 준비 | 안정 배포 + 환경변수 구성 |
| 4 | 우리 데이터 저장소 설계 | Supabase 프로젝트 생성, 팀에 맞는 표(테이블) 만들기, 데이터 직접 입력 | 팀별 테이블 + 초기 데이터 |
| 5 | 사이트와 데이터 연결 | 키 연결 → 우리 데이터가 화면에 나오는지 확인 | 데이터가 표시되는 사이트 |
| 6 | 핵심 기능 붙이기 | 팀별 필요 기능 구현 (등록·조회·신청·로그인 등 프로젝트에 맞게) | 팀별 핵심 기능 동작 |
| 7 | 점검 & 완성 | 동작 최종 확인, 자주 나는 오류 해결, 막힌 팀 따라잡기 | 완성된 팀 사이트 |
| 8 | 팀별 발표 & 공유 | 팀별 사이트 시연, 결과 공유, 마무리 Q&A | 발표·공유 마무리 |

### 체크포인트

- 2교시: 팀 사이트 주소 확보 (배포 성공).
- 5교시: 우리 데이터가 화면에 표시 (사이트-데이터 연결 성공).
